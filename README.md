# Slapdash

Slapdash is a self-hosted system that runs software bots on code
repositories and the applications that run from them. It has three parts:
the portal (the control plane), ShoddyBot (the bot framework) and the
runners (the framework that runs bots on infrastructure).

| Directory | What it is |
| --- | --- |
| [`portal/`](portal/) | The portal: control plane server and web UI. See [`portal/README.md`](portal/README.md) to run and deploy it. |

Contributors and coding agents: read [`AGENTS.md`](AGENTS.md) first.
